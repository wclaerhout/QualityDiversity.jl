Metrics

QualityDiversity.qd_score — Function
qd_score(archive; offset=0)

Sum of fitness + offset over the occupied cells of archive. The offset keeps negative fitness values from lowering the score; use fitness_offset of the problem as a starting point.

The method for any AbstractArchive makes one pass over elites. An archive that keeps running totals specializes it, as GridArchive does.

QualityDiversity.cqd_score — Function
cqd_score(archive; targets, fitness_range, penalties=10, distance_max) -> CQDScore
cqd_score(rng::AbstractRNG, archive; num_targets, fitness_range, penalties=10,
          distance_max, bounds=descriptor_bounds(archive)) -> CQDScore

The continuous quality-diversity score of Kent, Branke, Gaier and Mouret (2022), "A discretization-free metric for assessing quality diversity algorithms"; pyribs cqd_score. It measures an archive without reference to its cells: a user asks for a solution near a target descriptor G and accepts a distance from it at a price θ, and the archive recommends the elite that maximizes

ω = f / (f_max - f_min) - θ * norm(d - G) / distance_max

where f is the elite's fitness and d its descriptor. The score is the sum of the recommended ω over every target and every weight. As in the paper and in pyribs, the fitness is divided by the range, not shifted by f_min.

  • targets: descriptor points, each with the archive's number of dimensions. The second form draws num_targets of them uniformly within bounds with rng; the paper draws new targets for every run.
  • fitness_range = (f_min, f_max): the bounds of the fitness, from the problem or from all the runs being compared; it has no default.
  • penalties: the weights θ, or their number, spread evenly over [0, 1] with both ends included (a single weight is 0).
  • distance_max: the largest distance in descriptor space, by default the diagonal of descriptor_bounds(archive); an archive without bounds, such as an UnstructuredArchive, needs it given.

Throws an ArgumentError for an empty archive, a target of the wrong dimension or not finite, or invalid ranges. The time is proportional to the number of elites times the number of targets times the number of weights. To follow the score during a run, compute it in the callback of solve.

Example

julia> using QualityDiversity, StaticArrays

julia> archive = GridArchive((2,), ((0, 1),));

julia> QualityDiversity.add!(archive, [0.0], Evaluation(1.0, SVector(0.25)));

julia> r = cqd_score(archive; targets=[[0.25], [0.75]], fitness_range=(0, 2), penalties=[0, 1]);

julia> r.score, r.per_penalty
(1.5, [0.5, 0.25])

QualityDiversity.CQDScore — Type
CQDScore

The result of cqd_score: score, the continuous QD score; penalties, the penalty weights; per_penalty, the mean of ω over the targets for each weight, in the order of penalties; and num_targets. score is num_targets * sum(per_penalty). With Makie loaded, lines(result) plots per_penalty against penalties.

Several objectives

QualityDiversity.hypervolume — Function
hypervolume(points, reference_point) -> Float64

Hypervolume of a set of points, vectors of objective values that are maximized: the volume of the region that the points dominate and that lies above reference_point. A point contributes only if it is larger than the reference point in every objective, and a dominated point adds nothing. The empty set has volume 0.

For two objectives it sorts the points and adds the areas of the steps under them. For more it slices along the last objective and takes the hypervolume of each slice, which takes time of the order of n^(m-1) for n points and m objectives and suits the small sets that a Pareto front in a cell has.

Example

julia> using QualityDiversity

julia> hypervolume([[3.0, 1.0], [2.0, 2.0], [1.0, 3.0]], [0.0, 0.0])
6.0

julia> hypervolume([[1.0, 1.0, 1.0], [2.0, 2.0, 0.5]], [0.0, 0.0, 0.0])
2.5

QualityDiversity.global_hypervolume — Function
global_hypervolume(archive::ParetoGridArchive)

Hypervolume of the Pareto front of all the solutions of the archive, from every cell, computed with hypervolume: for n solutions, num_solutions, and M objectives it takes time of the order of n log n for two objectives and n^(M-1) log n for more. Zero for an empty archive.

Plotting

Loading Makie (for example using CairoMakie) adds plot recipes for archives; see Plotting archives.

QualityDiversityMakieExt — Module
QualityDiversityMakieExt

Makie support for archives. heatmap(archive), heatmap!(ax, archive) and plot(archive) draw an archive with two descriptor dimensions as a heatmap of the elite fitness, with the descriptor dimensions on the axes and the empty cells left transparent.

  • GridArchive: one rectangle per cell.
  • CVTArchive: the Voronoi cells, sampled on a pixels by pixels grid (200 by default; pass pixels=...).
  • CategoricalArchive: one square per combination of categories, on categorical axes that are labelled with the category values. Makie sorts the values of each axis, so they need isless.
  • ParetoGridArchive: the hypervolume of the front of each cell.
  • ThresholdArchive: the result archive, as solve returns it.
  • SpreadArchive: the archive it wraps.
  • DensityArchive: its result archive.

ecdfplot(archive) draws the empirical distribution function of the elite fitness of any archive with a single real fitness, as pyribs's archive_ecdf: the fraction of elites with fitness at most each value. An archive that wraps a result archive, such as a ThresholdArchive, shows its result archive.

lines(result) for a CQDScore plots the mean of ω over the targets against the penalty weight, the figure of Kent et al. (2022).

An archive with another number of descriptor dimensions throws an ArgumentError.
