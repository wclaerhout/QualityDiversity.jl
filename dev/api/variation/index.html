Variation

A variation operator makes a child from one or two parents. The operators below work on vectors of real numbers; a genotype of another type gets a vary method for an operator of its own, as in the graph tutorial.

Interface

QualityDiversity.AbstractVariation — Type
AbstractVariation

Supertype of variation operators, which turn one or two parent genotypes into a child.

Required methods

A mutation defines vary(rng, op, parent); a crossover defines vary(rng, op, p1, p2) and n_parents(op) returning 2.

A user with a custom genotype defines a new operator type and a vary method for it.

source
QualityDiversity.vary — Function
vary(rng::AbstractRNG, op::AbstractVariation, parent)
vary(rng::AbstractRNG, op::AbstractVariation, p1, p2)

One child of parent, or of the parents p1 and p2. Does not modify its parents, and returns a new object, not one of them: the parents are the genotypes the archive stores, and the child becomes one if the archive takes it. An operator that changed its parent in place would change an elite, which then no longer belongs to its cell. test_variation checks this.

source
QualityDiversity.n_parents — Function
n_parents(op::AbstractVariation) -> Int

Number of parents op combines: 1 for a mutation, which is the default, and 2 for a crossover. VariationEmitter draws that many parents from the archive for each child. The value must be known from the type of op, so that the choice is made at compile time.

Operators

QualityDiversity.GaussianMutation — Type
GaussianMutation(σ)

Mutation that adds independent Normal(0, σ) noise to every entry of a real-valued vector. σ must be positive and finite.

vary(rng, op, parent) returns a new array with the indices of parent, made with similar (a Vector for a Vector), whose entries have the floating-point type of those of parent: Float32 for a Vector{Float32}, Float64 for an integer vector. σ is converted to that type. parent is left unchanged.

source
QualityDiversity.IsoLineVariation — Type
IsoLineVariation(σ_iso, σ_line)
IsoLineVariation(; σ_iso=0.01, σ_line=0.2)

Crossover for real-valued vectors that moves along the line through two parents (Vassiliades and Mouret, 2018). For parents p1 and p2 the child is

p1 + σ_iso * z + σ_line * u * (p2 - p1)

with z a vector of independent standard normal numbers and u one standard normal number. The first noise term spreads the child around p1 in every direction (isotropic), the second stretches it along the line to p2. Both standard deviations must be non-negative and finite; σ_line = 0 leaves a Gaussian mutation of p1, and both zero a copy of p1.

The two parents must have the same indices. vary(rng, op, p1, p2) returns a new array with those indices, made with similar from p1 (a Vector for a Vector), whose entries have the floating-point type that the entries of the two parents promote to: Float32 for two Vector{Float32}s. The standard deviations are converted to that type. The parents are left unchanged.

Example

prob = Rastrigin(10)
alg = MAPElites(prob; dims=(20, 20), variation=IsoLineVariation(0.01, 0.2))

QualityDiversity.PolynomialMutation — Type
PolynomialMutation(lower, upper; eta=20.0, proportion=1.0)

Mutation for real-valued vectors in a box, the bounded polynomial mutation of Deb and Goyal (1996) used in NSGA-II. Each entry is changed with probability proportion. A changed entry moves by a random step whose density falls off polynomially with the distance, and the step is drawn so that the result never leaves [lower, upper]: near a bound the steps shrink on that side, and an entry exactly on a bound only moves inward. Larger eta gives smaller steps; the usual values are 5 to 50. A step has size about (upper - lower) / (eta + 1).

lower and upper are numbers, the same for every entry, or vectors with one bound per entry. Both must be finite and lower < upper. eta must be non-negative and proportion between 0 and 1; the textbook value of proportion is 1 / n for vectors of length n.

vary(rng, op, parent) requires every entry of parent to lie inside the bounds, and throws an ArgumentError otherwise; an archive fed by other operators or by a random_solution that ignore the bounds can hold such a parent, so give every emitter of a run the same bounds. It returns a new array with the indices of parent, made with similar (a Vector for a Vector), with the element type of parent (Float64 for integers), and leaves parent unchanged.

Changing an entry takes two floating-point powers, about 50 ns, so a child of 20 entries costs around 1 µs where a GaussianMutation takes under 100 ns; a proportion below 1 reduces it in proportion.

The mutation in QDax (polynomial_mutation) differs from the original in the power term, δ where the original has 1 - δ. There, an entry on a bound never moves, and one near it is often clipped onto it. This implementation follows the original, as pymoo does.

Example

julia> using QualityDiversity, Random

julia> op = PolynomialMutation(-5.12, 5.12; eta=20);

julia> child = QualityDiversity.vary(Xoshiro(1), op, [5.12, 0.0, -5.12]);

julia> all(-5.12 .<= child .<= 5.12)
true

QualityDiversity.UniformCrossover — Type
UniformCrossover(; proportion=0.5)

Crossover for genotypes that are vectors of any element type. Each entry of the child is taken from the second parent with probability proportion, and from the first parent otherwise. With proportion = 0 the child copies the first parent and with 1 the second. The parents must have the same indices.

It works for real numbers, integers, symbols or any other entries, since it only copies them. It does not create values that neither parent has; combine it with a mutation for that, for example in two emitters.

vary(rng, op, p1, p2) returns a new array with the indices of the parents, made with similar from p1 (a Vector for a Vector), whose element type holds the entries of both parents, and leaves the parents unchanged.

QDax calls its version of this operator polynomial_crossover; it copies a random subset of entries, drawn with replacement, from the second parent.

Example

julia> using QualityDiversity, Random

julia> child = QualityDiversity.vary(Xoshiro(1), UniformCrossover(), [1, 2, 3, 4], [5, 6, 7, 8]);

julia> all(c -> c in (1, 5) || c in (2, 6) || c in (3, 7) || c in (4, 8), child)
true
