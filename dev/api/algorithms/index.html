Algorithms and solving

An algorithm is an archive and a tuple of emitters. The constructors below assemble the usual combinations; QDAlgorithm takes any other.

Algorithms

QualityDiversity.QDAlgorithm — Type
QDAlgorithm(archive, emitters)

A quality-diversity algorithm: an archive and a tuple of emitters. Every algorithm shares one ask → evaluate → add → tell loop; they differ in which archive and emitters they combine.

emitters is a Tuple so that the loop over emitters is unrolled and type-stable. An emitter with state may appear in it once: it keeps the batch it asked for until tell!, so one instance cannot run twice in a round. Build several alike with a comprehension.

The algorithm runs through the CommonSolve.jl interface: init creates a state, step! performs one round, solve! runs to the budget, and solve does init and solve! in one call.

QualityDiversity.MAPElites — Function
MAPElites(prob; dims, bounds=nothing, batch_size=64, variation=GaussianMutation(0.1),
          genotype=default_genotype(prob), fitness=Float64, outside=ClampOutside(),
          phenotype=Nothing, device=nothing) -> QDAlgorithm

MAP-Elites: an archive laid out by the problem's descriptor space, and one VariationEmitter that applies the variation operator to batch_size children per round, with parents chosen uniformly from the archive. variation can be a mutation such as GaussianMutation or a crossover such as IsoLineVariation.

For a problem with descriptor_bounds, the archive is a GridArchive with dims cells along each descriptor dimension, laid out over bounds, by default the bounds of the problem; dims is required. For a problem with descriptor_categories, it is a CategoricalArchive with one cell for each combination of categories; dims and bounds do not apply and are an error. outside and phenotype are passed to the archive; see GridArchive and CategoricalArchive. A descriptor outside the bounds goes to the nearest cell by default, as in pyribs and QDax, so that a random initial population never stops a run; pass outside=ThrowOutside() to catch a descriptor function that does not match its bounds. A category has no nearest cell, so the default for a problem with categories is ThrowOutside(). A problem that returns a phenotype needs phenotype set to its type. The archive stores genotypes of the type that random_solution returns, see default_genotype; genotype overrides it.

Everything runs on the host unless device names an array type, such as CuArray: then the archive is a DeviceGridArchive in arrays of that type and the emitter a DeviceVariationEmitter, so the variation, the evaluation and the insertion of a batch stay on the device. That needs a problem with descriptor_bounds, real-vector genotypes, no phenotype, and a variation that the device emitter supports.

Example

prob = QualityDiversity.Benchmarks.Rastrigin(10)
result = solve(prob, MAPElites(prob; dims=(20, 20)); budget=100_000, rng=Xoshiro(1))
coverage(result.archive)
source
MAPElites(archive::AbstractArchive; batch_size=64, variation=GaussianMutation(0.1))
    -> QDAlgorithm

MAP-Elites over any archive: archive with one VariationEmitter that applies variation to batch_size children per round, or a DeviceVariationEmitter for a DeviceCellArchive. Use it to run MAP-Elites with an archive other than the grid, such as a CVTArchive or a DeviceCVTArchive.

Example

prob = QualityDiversity.Benchmarks.Rastrigin(10)
archive = CVTArchive(prob; cells=500, rng=Xoshiro(1))
result = solve(prob, MAPElites(archive); budget=100_000, rng=Xoshiro(2))

QualityDiversity.CMAME — Function
CMAME(prob; dims, sigma0, n_emitters=5, batch_size=<CMA-ES default>,
      ranker=TwoStageImprovementRanker(), selection=FilterSelection(),
      restart=NoImprovementRestart(), x0=nothing, lower=-Inf, upper=Inf,
      bounds=nothing, genotype=default_genotype(prob), fitness=Float64,
      outside=ClampOutside(), phenotype=Nothing, device=nothing) -> QDAlgorithm

CMA-ME (Fontaine et al., 2020): a GridArchive with dims cells along each descriptor dimension, as for MAPElites, and n_emitters independent CMAEmitters, each with its own search distribution. The emitters are the improvement emitter of the paper: candidates ranked by what the archive did with them, the ones the archive accepted recombined, and a restart from a random elite when a batch is rejected entirely. The paper runs 15 emitters of 36 candidates; the default is 5 emitters with the batch size of CMA-ES, 4 + floor(3 log(dim)), so pass n_emitters=15, batch_size=36 for its settings.

sigma0 is the initial step size of the search distributions and has no default, because it depends on the scale of the solutions. The solutions must be real vectors; their length is that of random_solution(rng, prob). lower and upper bound the solutions, and x0 gives the mean of the first distribution of every emitter, by default a random elite. The other arguments are those of MAPElites and CMAEmitter.

With device, an array type such as CuArray, the archive is a DeviceGridArchive and the emitters are the searches of one DeviceCMAEmitter: all searches ask together, and their candidates are evaluated and added on the device as one batch, so each search sees the archive as it was before the round. That pays off with many emitters, hundreds rather than five.

Example

prob = QualityDiversity.Benchmarks.Rastrigin(10)
result = solve(prob, CMAME(prob; dims=(20, 20), sigma0=1.0); budget=50_000, rng=Xoshiro(1))
qd_score(result.archive; offset=fitness_offset(prob))
source
CMAME(archive::AbstractArchive; sigma0, dim, n_emitters=5, kwargs...) -> QDAlgorithm

CMA-ME over any archive, such as a CVTArchive: archive with n_emitters CMAEmitters for solutions of length dim. The keyword arguments are those of CMAEmitter. For a DeviceCellArchive the emitters are the n_emitters searches of one DeviceCMAEmitter.

QualityDiversity.CMAMAE — Function
CMAMAE(prob; dims, sigma0, threshold_min, learning_rate=0.01, n_emitters=5,
       batch_size=<CMA-ES default>, ranker=ImprovementRanker(),
       selection=MuSelection(), restart=ConvergenceRestart(), x0=nothing,
       lower=-Inf, upper=Inf, bounds=nothing, genotype=default_genotype(prob),
       fitness=Float64, outside=ClampOutside(), phenotype=Nothing) -> QDAlgorithm

CMA-MAE (Fontaine and Nikolaidis, 2023): CMAEmitters as for CMAME but ranking candidates by their improvement over the threshold of their cell, recombining the best half, and restarting only on convergence, over a ThresholdArchive around a GridArchive. threshold_min, the lowest fitness the problem can produce, and learning_rate are those of the ThresholdArchive. Because the elites of that archive can get worse, solve returns its result archive, which holds the best solution of every cell. The paper runs 15 emitters of 36 candidates; see CMAME for the default. The other arguments are those of CMAME, without device: the threshold archive runs on the host.

QualityDiversity.CMAMEGA — Function
CMAMEGA(prob; dims, sigma0, optimizer=AdamAscent(), n_emitters=1,
        batch_size=<CMA-ES default>, ranker=TwoStageImprovementRanker(),
        selection=FilterSelection(), restart=NoImprovementRestart(), x0=nothing,
        normalize=true, bounds=nothing, genotype=default_genotype(prob), fitness=Float64,
        outside=ClampOutside(), phenotype=Nothing) -> QDAlgorithm

CMA-MEGA (Fontaine and Nikolaidis, 2021, "Differentiable Quality Diversity"): a GridArchive with dims cells along each descriptor dimension, as for MAPElites, and n_emitters GradientArborescenceEmitters, which step along the gradients of the fitness and the descriptor. The problem must provide them; see evaluate_gradient. The ranking, selection and restart rules and the optimizer are those of CMA-MEGA (Adam) in the paper, which runs one emitter of 36 candidates. The default batch size is that of CMA-ES over the N + 1 gradient coefficients, 4 + floor(3 log(N + 1)) for N descriptor dimensions, as in pyribs; pass batch_size=36 for the setting of the paper.

sigma0 is the initial step size of the distribution of the gradient coefficients and has no default; the paper uses 10 on the sphere and Rastrigin benchmarks. The other arguments are those of MAPElites and GradientArborescenceEmitter.

Example

prob = QualityDiversity.Benchmarks.Sphere(100)    # gradients in closed form
result = solve(prob, CMAMEGA(prob; dims=(100, 100), sigma0=10.0); budget=20_000, rng=Xoshiro(1))
coverage(result.archive)

CMAMAEGA(prob; dims, sigma0, threshold_min, learning_rate=0.01, optimizer=AdamAscent(),

QualityDiversity.OMGMEGA — Function
OMGMEGA(prob; dims, sigma0, batch_size=64, normalize=true, bounds=nothing,
        genotype=default_genotype(prob), fitness=Float64, outside=ClampOutside(),
        phenotype=Nothing) -> QDAlgorithm

OMG-MEGA (Fontaine and Nikolaidis, 2021, "Differentiable Quality Diversity"): MAP-Elites whose children are gradient steps from their parents, a GradientArchive around a GridArchive with dims cells along each descriptor dimension and a GradientOperatorEmitter. Every solution of the run is evaluated with its gradients; see evaluate_gradient. sigma0, the standard deviation of the gradient coefficients, has no default; the paper uses 10 on the sphere and Rastrigin benchmarks. The paper draws 36 children per round; the default batch_size=64 is that of MAPElites. The other arguments are those of MAPElites and GradientOperatorEmitter.

QualityDiversity.DDS — Function
DDS(prob; dims, sigma0, bandwidth, buffer_capacity=10_000, rng=Random.default_rng(),
    n_emitters=15, batch_size=36, ranker=ImprovementRanker(), selection=MuSelection(),
    restart=ConvergenceRestart(), x0=nothing, lower=-Inf, upper=Inf, bounds=nothing,
    genotype=default_genotype(prob), fitness=Float64, outside=ClampOutside(),
    phenotype=Nothing) -> QDAlgorithm

Density Descent Search with a kernel density estimate (DDS-KDE; Lee et al., 2024): a DensityArchive around a GridArchive with dims cells, and n_emitters CMAEmitters that rank their candidates by the density of the descriptors found so far, lowest first, recombine the best half and restart on convergence, the settings of the paper. It searches for diversity alone: the fitness only decides which solution the grid keeps in a cell. bandwidth, buffer_capacity and rng, which drives the buffer, are the arguments of the DensityArchive. For a reproducible run, seed DDS as well as solve, e.g. rng=Xoshiro(1): without it, rng is Random.default_rng(), which the seed of solve does not set. The other arguments are those of CMAME, without device: the density archive runs on the host.

Density descent drives the searches toward empty regions, also out of the region where the problem's descriptors change. On a problem that clips its solutions to a box, such as Rastrigin, a search outside the box sees the descriptors of the edge of the box, and with the default strategy it seldom converges, so it seldom restarts. Pass the box as lower and upper to keep the searches inside. With strategy=QualityDiversity.PyribsCMAES such a search restarts, as in pyribs: its rank-one covariance term grows with the square of the step size, and the covariance matrix becomes ill-conditioned.

Example

prob = QualityDiversity.Benchmarks.Rastrigin(10)
alg = DDS(prob; dims=(20, 20), sigma0=0.5, bandwidth=0.5, rng=Xoshiro(1))
result = solve(prob, alg; budget=50_000, rng=Xoshiro(2))
coverage(result.archive)

QualityDiversity.MOME — Function
MOME(prob; dims, reference_point=reference_point(prob), max_front=50, batch_size=64,
     variation=GaussianMutation(0.1), bounds=nothing, genotype=default_genotype(prob),
     outside=ClampOutside(), duplicates=RejectDuplicates(), full_front=RejectNewcomer(),
     phenotype=Nothing) -> QDAlgorithm

Multi-objective MAP-Elites (Pierrot et al., 2022): a ParetoGridArchive, which keeps a Pareto front of at most max_front solutions in each cell of a grid with dims cells along each descriptor dimension, and one VariationEmitter that applies variation to batch_size children per round. A parent is a solution drawn uniformly from the front of a cell drawn uniformly among the occupied ones. The problem returns a vector of objectives as its fitness. reference_point is the corner from which hypervolume is measured; a problem can supply it with reference_point. duplicates and full_front decide about a solution whose objectives equal those of a stored one and about one for a full front; see ParetoGridArchive. With full_front=QualityDiversity.ReplaceCrowded() the archive keeps fronts as MOME-PGX does (Janmohamed et al., 2023), whose crowding-based selection of parents and policy-gradient variation are not part of this constructor. The default variation is that of MAPElites; the MOME paper uses polynomial mutation with eta=1 together with a crossover on its Rastrigin benchmarks, and variation=PolynomialMutation(lower, upper; eta=1) is the mutation alone.

solve returns the archive, and a run records its MOQD score, coverage, the largest hypervolume of a cell and the number of solutions.

Example

prob = QualityDiversity.Benchmarks.BiSphere(10)
result = solve(prob, MOME(prob; dims=(20, 20)); budget=50_000, rng=Xoshiro(1))
qd_score(result.archive), global_hypervolume(result.archive)

MOME(archive::ParetoGridArchive; batch_size=64, variation=GaussianMutation(0.1)) -> QDAlgorithm

MOME over a given archive: archive with one VariationEmitter.

QualityDiversity.MELS — Function
MELS(prob::SampledSpread; dims, batch_size=64, variation=GaussianMutation(0.1),
     bounds=nothing, genotype=default_genotype(prob), fitness=Float64,
     outside=ClampOutside(), phenotype=Nothing) -> QDAlgorithm

MAP-Elites with low spread (Mace et al., 2023): MAP-Elites for a noisy problem in which an elite is replaced only by a solution with higher fitness and no larger spread, the mean distance between the descriptors of its evaluations. The archive is a SpreadArchive around a GridArchive with dims cells along each descriptor dimension, and one VariationEmitter applies variation to batch_size children per round.

prob is a SampledSpread problem, which evaluates every solution n_samples times; pass the same problem to solve. The other arguments are those of MAPElites.

Example

noisy = StochasticQDProblem((rng, x) -> (-sum(abs2, x), (x[1], x[2]) .+ 0.05 .* randn(rng, 2));
                            init=rng -> randn(rng, 5), bounds=((-3, 3), (-3, 3)))
prob = SampledSpread(noisy; n_samples=10)
result = solve(prob, MELS(prob; dims=(20, 20)); budget=200_000, rng=Xoshiro(1))

Running

CommonSolve.solve — Function
solve(prob, alg::QDAlgorithm; budget, rng=Random.default_rng(), callback=nothing,
      init_size) -> QDResult

Run alg on prob until budget evaluations are spent: solve!(init(prob, alg; ...)). The keyword arguments are those of init. alg is not modified, so it can be solved again.

source
CommonSolve.init — Function
init(prob, alg::QDAlgorithm; budget, rng=Random.default_rng(), callback=nothing,
     init_size=<sum of the emitters' batch sizes>) -> QDState

Prepare a run. The archive and emitters of alg are copied, so alg is not modified, and the copy is filled with init_size solutions from random_solution.

budget is the number of evaluations, including the initial ones. A problem that evaluates a solution several times, such as Sampled, counts every one. A run stops at the first step that reaches it, so it can overshoot by less than one round of emitter batches. callback(state) is called after initialization and after every step. Pass a seeded rng for a reproducible run.

source
CommonSolve.step! — Function
step!(state::QDState)

One round: for each emitter in turn, ask for candidates, evaluate them, add them to the archive, and tell the emitter the outcome. Then record the metrics and call the callback. An emitter that needs gradients first gets the points it asks for with ask_gradients evaluated with their gradients and added to the archive.

source
CommonSolve.solve! — Function
solve!(state::QDState) -> QDResult

Step until the evaluation budget is reached. Returns immediately if it already has been.

source
QualityDiversity.QDState — Type
QDState

State of a running algorithm, created by init(prob, alg; ...). It holds the problem, working copies of the algorithm's archive and emitters, the random number generator, the number of evaluations so far, and history, a vector with the metrics of the result archive after initialization and after every step.

Fields are read with state.archive, state.n_evals, state.history, and so on.

source
QualityDiversity.QDResult — Type
QDResult

Outcome of solve: the archive of the best solutions found, which is result_archive of the algorithm's archive, the metrics history, and the number of evaluations n_evals.
