Choosing an algorithm

Every algorithm is an archive and a tuple of emitters. The constructors below choose both with the settings of the paper that introduced the algorithm; the API reference gives every keyword.

A few rules of thumb:

  • Start with MAP-Elites. It works with any genotype for which you can write a variation operator, and its one parameter that matters is the size of the mutation.
  • Real vectors with many parameters: the CMA emitters adapt the shape of their search to the problem and usually reach better fitness than a fixed Gaussian mutation. sigma0, the initial step size, has no default because it depends on the scale of the solutions; a tenth to a half of the range of a parameter is a usual start.
  • CMA-ME or CMA-MAE: CMA-MAE keeps searching where it has already found good solutions, which CMA-ME abandons once a region is covered. It needs threshold_min, the lowest fitness the problem can produce.
  • Gradients: when the fitness and the descriptor are differentiable functions of a real vector, the algorithms of differentiable quality diversity step along their gradients and fill an archive in far fewer evaluations than the others. Load ForwardDiff.jl (using ForwardDiff) to compute the gradients of a QDProblem, or define evaluate_gradient for the problem. CMA-MEGA computes the gradients once per round, at one point; OMG-MEGA computes them for every solution, which costs more when a gradient is expensive.
  • Noisy problems: wrap the problem in Sampled to average several evaluations; use MELS when the descriptor is noisy too. See the noisy problems tutorial.

Archives

The constructors pick a grid, but any archive can be given to MAPElites, CMAME and the others in place of the problem:

archive = CVTArchive(Xoshiro(1), prob; cells=1_000)
alg = MAPElites(archive; batch_size=100)

A descriptor outside the bounds of a grid is an error by default, which catches a descriptor function that does not match its bounds. Pass outside=ClampOutside() to put it in the nearest cell, or outside=RejectOutside() to discard it.

Combining emitters

QDAlgorithm takes any archive and any tuple of emitters, for example a Gaussian and an iso-line emitter side by side:

archive = GridArchive(prob; dims=(50, 50))
emitters = (VariationEmitter(GaussianMutation(0.1); batch_size=50),
            VariationEmitter(IsoLineVariation(0.01, 0.2); batch_size=50))
alg = QDAlgorithm(archive, emitters)

All emitters run every round. A BanditScheduler instead holds a pool of emitters and runs the most successful few each round.
